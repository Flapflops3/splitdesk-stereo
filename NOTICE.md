# Third-party materials

SplitDesk Stereo original source and the supplied native builds are licensed under GPL-3.0-only. The corresponding C sources are in `mixer/filters.c` and `mixer/tray.c`. Build commands are in the installation guide.

The American Walnut Veneer photograph used for the mixer enclosure is a CC0 texture from [Poly Haven](https://polyhaven.com/a/american_walnut_veneer). The app renders its own stain, panel and controls. The stereo test recording is generated by `tools/make_demo.py`.

Sunshine, Moonlight, VB-CABLE and Steam Streaming Speakers are independent projects or products with their own licensing. Install drivers from their official distributors. The installer fetches uv if necessary, a managed CPython runtime and the Python packages listed in requirements.txt. Their upstream licenses and distribution metadata accompany those packages. Sunshine and Moonlight names describe compatibility. This is an independent project.
